# Your published work

Add your poems, essays, performances, sessions, projects and selected moments here through Pages CMS.

Each entry should have:
- A title
- A section: words, sounds, stories or moments
- A short introduction
- A date (optional)
- A full body
- Status set to `published` when ready to appear on the website

Tick **Show in portfolio** for work you want featured on the Portfolio page.

Do not put private contact details in public posts.
